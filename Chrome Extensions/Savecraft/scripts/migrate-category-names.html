SaveCraft — Category Rename Migration

This PATCHES existing curated_items docs in place (Firestore update(), not a full re-seed) — it only ever touches the category field, never title/url/imageUrl/notes/folderId. It also PATCHES curated_lists docs' enabledCategories array and each entry's category field inside rows (leaving label/ titles untouched). Requires an already-signed-in browser session as lizpasekal@gmail.com in this browser (same account used for SaveCraft/the other seed and migration tools) — the Firestore rules already allow that account to write curated_items/curated_lists/curated_topics, same as scripts/migrate-curated-categories.html, which this tool is modeled closely on. This does NOT touch curated_topics — nothing in that collection carries a category string.

1. Sign in with your Firebase account in this browser (open the real SaveCraft app once if you haven't recently). 2. Click Preview to see exactly what would change with zero writes. 3. Click Run to actually apply it.
